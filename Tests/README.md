# 回归与验收

需要选择完整 Xcode；也可以给命令设置 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`。

```sh
bash Tests/run-activity-tests.sh
bash Tests/run-media-playback-tests.sh
bash Tests/run-music-spectrum-tests.sh
python3 Tests/check-architecture.py
bash Tests/run-island-transition-tests.sh
bash Tests/run-island-artwork-tests.sh
python3 -m unittest discover -s .github/scripts/tests
```

## 活动与架构

活动测试直接编译生产 `IslandActivity`、`ActivityScheduler` 和 `IslandPresentation`，不依赖 SwiftUI 或下载包。使用确定性时间验证：空闲、持续活动结束、系统反馈抢占与音乐恢复、按键合并、不同反馈替换、优先级、隐藏活动过期不补播、快速切换和呈现映射。另覆盖默认计时优先、手选音乐/计时、浏览待办不改变选择、待办、空页面及临时活动不可常驻、最新载荷、选中活动撤下后清除选择且不复活、切歌与系统反馈同级抢占/按期限恢复，以及待确认计时结束优先于手选与切歌。

个人活动测试还编译生产 `TimerSession`、列表筛选/写入目标模型、查询代次门闩及 `IslandPager`：验证暂停/恢复、睡眠后的截止、存储往返、到时强调和恢复、默认全部列表包含无日期/未来事项、创建时间升序让新事项排后（不受截止时间和标识字典序影响）、重复查询及改名/改截止时间保持顺序、缺失/相同创建时间稳定排序、同名列表按标识区分、新增的目标列表、删除/只读列表不回退写入、旧待办读取失效、阈值前阻力、过阈值立即提交、一次一页及不越界。

架构脚本限制活动模型/调度目录的依赖，防止重新启用原有的两条展示状态旁路。这是静态辅助检查，不是完整 Swift 依赖分析；新增业务来源与视图仍需按三层规范人工审查。

## 媒体与封面

媒体测试直接编译生产流读取器、状态模型与封面转换模型，覆盖分片 UTF-8、巨大封面、完整/增量/空快照、播放时间戳、EOF、取消、无效消息、网易云暂停/清空/队列元数据的序列、旧歌曲异步结果及高清封面原位更新。

这些检查不启动音乐应用，不能替代真实播放验收。

媒体模型还覆盖 QQ 音乐、网易云、Apple Music、Spotify 及通用来源的前后跳转进度与条目标识重建，验证歌曲身份及封面替换保持稳定，并保留真正切歌和同名不同艺人的识别。`bash Tests/run-island-artwork-tests.sh --playback-only` 在隔离来源副本中驱动生产 `MusicManager` 和真实调度器，检查进度、标识、封面刷新及同曲暂停恢复不生成切歌活动，实际新歌曲仍更新封面身份并提交提示，高清封面到达不重复提示；同时运行封面加载就绪检查。这不是上述播放器的真实操作验收。并发检查可通过 `AIRISLAND_ARTWORK_CHECK_ROOT` 指定独立输出和测试副本目录，避免互相覆盖。

## 动画轮廓回归

`bash Tests/run-island-transition-tests.sh [截图输出目录]` 在独立的离屏原生窗口中运行生产背景、轮廓与统一动画策略，不访问音乐来源或用户偏好。先验证 0/24/32/45 点物理安全区内纯黑、下缘无额外留白且渐变连续、音乐背景铺满底部全宽并向上线性渐隐；再检查三种收起高度、展开/收起、快速反向、过渡中的背景内容更新及减少动态效果；直接读取中间帧像素，验证圆角仍然存在、封面没有越界、顶部保持纯黑和尺寸连续变化。它覆盖裁剪与动画事务回归，完整 `ContentView` 和真实鼠标/触控板交互仍需另行验收。

`bash Tests/run-island-artwork-tests.sh` 构建生产 `ContentView` 的独立测试副本，以当前显示器参数逐帧检查精简/展开、横向歌曲速览/展开、快速反向和高清封面更新。测试副本关闭真实来源启动，使用独立偏好域；生产视图和调度代码保持原样，只插入封面出现次数计数、尺寸观察及减少动态效果的测试输入。用实际轮廓像素和只读布局尺寸同时验证宽高与封面缩放进度一致、持续单实例、圆角及无文字黑框遮挡，分别覆盖有/无光晕。启用真实网易云应用角标，检查其在过渡中始终附着于封面右下角，收起和系统反馈状态不残留角标；因此运行该检查需安装网易云音乐。构建日志和截图保留在 `build/checks/artwork-render-tests/`；可通过 `AIRISLAND_DERIVED_DATA` 和 `AIRISLAND_SOURCE_PACKAGES` 复用已有构建/包缓存。另外检查四类收起反馈、电源通知、无活动状态及恢复音乐；覆盖速览在展开时结束、收起中结束并快速反向，确认展开尺寸不被改变且最终恢复原始精简尺寸。测试中的稳定速览会刷新其期限，避免与单独的结束场景混淆。同时逐一触发音量、亮度、背光和麦克风活动，检查展开面板顶部没有图标、滑杆或数值，尺寸和展开状态保持不变。这仍是离屏验证，不能代替真实鼠标、触控板和音乐应用验收。

## 界面和真实应用验收

`bash Tests/run-island-artwork-tests.sh --reminders-only` 在隔离偏好与不连接 EventKit 的来源副本中渲染提醒事项未连接、权限拒绝、全部事项及指定列表页面，供检查文本按钮对齐和标题灰度层次；长列表另测原生滚动区域与新增按钮底边对齐并能滚到末行，比较计时开始与待办新增按钮在页面中的实际位置和 44 点尺寸，保存末尾及计时页截图；不请求或修改用户的提醒事项权限与数据。

`bash Tests/run-island-artwork-tests.sh --focus-only` 在隔离偏好域和离屏生产 `ContentView` 中驱动真实分页处理方法，验证手势选择音乐、圆点选择计时、空待办页不改写常驻项、音乐经有内容待办页滑至空计时页后启动/暂停/收起/反馈恢复保持新计时常驻、重开页面、切歌速览真实到期恢复、系统反馈恢复、关闭来源清除选择，以及计时到时强制展开/关闭后恢复。自动计时提醒不改写常驻选择。开启音乐背景后读取实际页面像素，验证音乐页显示、提醒事项和计时页保持纯黑背景；逐帧检查慢滑和回弹的音乐背景底边仍延伸至岛底，并检查音乐背景移至岛内的边缘仍有自身圆角，验证背景开关即时生效。保存切歌速览与恢复计时的截图；该检查也包含在完整封面测试中，不等同于真实触控板或音乐应用验收。

`bash Tests/run-island-artwork-tests.sh --alarm-only` 连续采样生产闹钟图标、真实计时页及自动/已展开岛的 45 帧，要求可见状态产生至少 8 个不同渲染帧；减少动态效果、非当前页面时必须保持同一静态帧。这项检查也包含在个人活动运行时检查和完整封面检查中，不用静态截图代替动画验证。

`bash Tests/run-island-artwork-tests.sh --compact-only` 离屏渲染生产收起界面，在 24/32 点高度检查计时、音乐及四类系统反馈的实际像素左右留白，确认内容未进入居中的刘海安全区；较长的小时计时应自动增加岛宽，仍受窗口预算限制。另以 120／185／320 点基础宽度验证两种高度及所有收起状态不超出窗口；直接调用生产尺寸规则检查屏宽比例、展开倍数、两种尺寸上下限、偏好保存、真实显示器适配和有刘海屏幕不受宽度偏好影响，并保存显示与交互设置截图。完整检查还覆盖无刘海屏幕 5%／10% 时的展开、收起和快速反向中间帧。只验证呈现层，不操作真实提醒事项。完整封面测试也包含该检查。

原生封面测试附带个人活动运行时检查，也可用 `bash Tests/run-island-artwork-tests.sh --personal-only` 单独执行：在隔离测试偏好域调用真实计时源和调度器，检查替换后的旧截止任务、暂停/继续、待确认状态不超时、重复同步/停止音乐不撤下提示；覆盖恢复待确认记录、收起时到时、音乐展开时到时三种完整计时页呈现，检查鼠标/快捷键共用的关闭路径不提前收起，关闭后清除记录、收起并恢复音乐，以及关闭功能撤下状态并清除本项计时记录。离屏渲染真实时间滚轮及空闲/暂停/结束页面、统一的完整结束页和减少动态效果下的结束页；检查空闲计时页直接包含三组原生滚轮，改动选择值后开始、暂停、重置能够恢复默认选择，且无整页编辑锁；验证结束页真实重新计时操作沿用原时长、生成新标识并持久化、撤下旧提示；真实关闭操作清除记录并恢复音乐。验证滚轮初始化不改变分钟值，并测量八种图标按钮（含重新计时、关闭和禁用状态）均为 44 × 44。不会连接用户提醒事项或操作用户原应用偏好。截图位于同一 frames 目录。这不代替真实鼠标/触控板操作、权限授权/撤回、iCloud 同步和真实录屏/多屏交互验收。

封面渲染测试也覆盖暂停后的上一曲/下一曲翻转和翻转中的高清封面更新，逐帧检查封面边缘没有未变暗的像素；切歌等待时检查封面保持原大小和亮度。该场景使用真实生产视图，在隔离副本中开放歌曲标识、翻转方向和切歌等待状态的测试写入，不启动播放器。媒体模型测试另验证慢加载、失败超时、手动暂停、快速连续请求、来源切换/退出及真实播放状态和速率不被等待状态覆盖。

暂停边缘检查以均匀封面的内部亮度为上限，连同低覆盖率的抗锯齿边缘一起检查，防止只用宽松阈值漏掉细亮线。测试副本同时开放 `MusicManager.updateFromPlaybackState`，直接验证生产异步解码在歌曲未就绪时保留旧封面、双条件就绪后提交最新封面、高清升级保持身份、失败/恢复不提前翻转。媒体会话测试重放本机采集的临时 UUID、零速率播放和元数据/封面分批更新顺序；这些检查仍不等同于所有网络状况的真实验收。

Release 构建必须通过。影响界面的变更还需验证：

- 设置四分类、活动子页返回、中文文案、窗口最小尺寸。
- 音乐展开布局、长歌曲名、暂停和无播放内容；确认不再出现文件暂存入口，新分页仅为音乐、提醒事项和计时器。
- 原生触控板横向手势过阈值只切一页，松手惯性不继续推页；时间滚轮纵向选中项与实际时长一致，触感遵守总开关。旧双指上下展开/收起入口不再存在。
- 系统提醒事项首次连接、拒绝、撤回、默认全部事项、具体列表选择、同名/只读/已删除列表、无默认可写列表、无日期/未来事项、快速切换列表与外部新增/完成/删除；不得把模型测试当作实际 EventKit/iCloud 同步验收。
- 连续切歌，高清封面到达只更新一次，不重复翻转。
- 播放中调音量/亮度，短暂反馈结束后恢复音乐；展开时四种系统反馈均不显示，顶部保持纯黑且面板不被强制收起。
- 活动开关即时生效，辅助功能拒绝后可恢复；首次使用不再请求已移除的权限。
- 全屏、无刘海屏、多显示器、减少动态效果；拖入文件不再打开面板、接收或写入文件。

提交说明必须分别记录模型测试、构建、离屏渲染和真实应用操作；未执行的项目明确标记，不能用“测试通过”概括全部验收。

`bash Tests/run-island-artwork-tests.sh --pages-only` 在隔离来源和偏好域中覆盖提醒事项/计时器四种启用组合，读取原生截图中的实际分页圆点数量；验证移除正在编辑的待办页会退出输入并回到音乐、关闭中间页后音乐直接滑向计时器、关闭计时器会取消现有计时且移除页面、单页不响应横向手势、重新启用恢复分页，以及增删页面不会使进行中的展开动画直接跳到终点。不会连接 EventKit 或修改真实提醒事项。分页模型另验证索引重排保留页面身份、禁用页不可选、禁用中断手势和单页无回弹。

`bash Tests/run-island-artwork-tests.sh --motion-only` 在隔离来源/偏好域中点击生产主按钮与完成动作：检查计时立即启动/暂停/继续/取消，主按钮单实例、位置中间帧与快速反向连续，以及减少动态效果；提醒事项用受控写入结果替代 EventKit，只将真实生产页面、协调器及成功/失败返回路径接入。检查成功、失败、重复点击和最后一项完成的实际勾选像素，以及其余行补位的逐帧位置。它不写入用户系统提醒事项，不能替代真实 EventKit 写入/撤回权限验收。

`bash Tests/run-island-artwork-tests.sh --personal-paging-only` 在隔离来源/偏好域中检查计时运行、刚启动时与待办的双向慢滑、阈值提交、跳秒和未达阈值回弹，并覆盖减少动态效果。逐帧检查两页内容没有越界，同时追踪未变化的计时首位数字像素，确认其随页面连续移动；被岛的实际轮廓裁掉的区域不计为数字缺失。此检查不会连接 EventKit，不能代替真实触控板慢滑验收。

`bash Tests/run-island-artwork-tests.sh --music-entry-only` 读取生产音乐封面的实际像素位置，检查从待办/计时页返回时封面追随原速翻页落位、手势提交与取消、快速反向、封面身份不重建及减少动态效果；另按“浏览其他页 → 收起恢复音乐 → 再展开”的路径逐帧对照封面像素与岛的统一几何进度，确认不重播横向追入。不启动真实播放器，不代替真实触控板验收。

`bash Tests/run-music-spectrum-tests.sh` 编译生产频谱策略与 Accelerate 分析器，以 44.1/48 kHz 的六种正弦信号检查频段映射、静音回落、幅值有限且归一化、帧输出上限，以及启用/隐藏/暂停/未知来源、播放器/歌曲身份变化及过期帧拒绝，不访问系统音频。

`bash Tests/run-island-artwork-tests.sh --spectrum-only` 在禁止硬件采集的副本中，读取真实六柱像素、与封面同高的幅值上限及展开音乐页右上角的六柱像素，并在切歌速览中用无歌手字形干扰的尾部区域像素确认频谱已移除、结束速览后恢复，验证默认启用且旧频谱关闭偏好不再生效、多屏共用会话、展开音乐页保持同一采集代次、所有窗口切离音乐页后停止采集请求、重新收起拒绝旧帧、计时抢占/恢复及来源失联停止。另读取 1×/2× 栅格化图像及真实收起/展开界面的像素，要求六柱的可见宽度、五个间隔分别一致，覆盖分数间距造成的交替宽窄。它不申请权限，不能代替当前播放器 Tap 的真实采样、输出设备切换和权限拒绝/撤回验收。真实采集在音乐播放且频谱可见时按需请求系统音频采集授权；不把静态波形或模拟帧写成已验证真实音乐。

## 应用更新

见 [应用内更新说明](../docs/UPDATES.md)。`run-software-update-tests.sh` 直接编译生产更新服务，验证手动检查允许、后台检查拒绝；可选使用真实准备包检验 Ed25519 签名与篡改拒绝。发布准备脚本的行为回归纳入 `.github/scripts/tests`。这些检查不表示真实用户版本、权限和所有安装路径已经通过升级验收。

`bash Tests/run-island-artwork-tests.sh --settings-only` 使用实际设置窗口，在浅色/深色、最小/放大尺寸下切换分类、进入媒体子页并返回，读取标题在原生标题栏中的坐标，要求不落入左栏或正文，并保存完整窗口截图。它只验证运行测试的系统；其他 macOS 版本仍需真实环境验收。

原生渲染检查还会在隔离偏好域验证：未设置的提醒事项/计时器默认启用，显式关闭偏好仍有效；不清理实际用户的偏好或数据。

`bash Tests/run-island-artwork-tests.sh --onboarding-only` 检查欢迎窗口中的本地视频确实可播放、无音轨，停止请求或隐藏窗口时暂停，释放时清空队列；并检查中英文、浅色/深色的两步 560 × 560 布局及减少动态效果下不创建播放器，保存静态图示截图。测试使用隔离偏好域，不启动真实播放器、提醒事项或计时来源，不代表真实触控板分页或其他 macOS 版本均已验收。
