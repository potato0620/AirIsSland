# 安装、权限与更新

[返回软件介绍](../README.md) · [功能与交互说明](FEATURES.md)

## 系统要求与安装

发布包适用于 Apple Silicon Mac，要求 macOS 15 或更新版本。

1. 从[发布页](https://github.com/potato0620/AirIsSland/releases/latest)下载 DMG。
2. 将 AirIsland 拖入“应用程序”。替换旧版前先退出正在运行的 AirIsland。
3. 从“应用程序”打开 AirIsland，按需连接提醒事项或开启系统反馈。

发布页表示已发布版本，仓库主分支可能包含尚未发布的改动。内置媒体适配框架的最低系统为 15.0。

## 首次打开

当前公开发行包采用 ad-hoc 签名，尚未经过 Apple 公证。首次打开如被系统拦截，可在「系统设置 → 隐私与安全性」中允许打开。

## 应用更新

2.8.18 目前请从 GitHub Release 手动下载安装，应用内更新源暂未推送此版。

带更新器的版本可通过关于页或菜单栏的“检查更新…”手动检查、下载并确认安装重启；2.8.9 及更早版本需要先手动安装一次带更新器的版本。手动替换前先退出旧版应用；应用标识保持一致以保留偏好设置。已移除功能的旧偏好不再读取，无需清除所有设置。

## 权限与系统按键

系统反馈替换为可选功能，启用时才申请辅助功能权限。除标准媒体键外，也兼容通过 F14/F15 发送的亮度功能键（例如 HHKB 的 Fn+O/P）；保留 Command/Control 组合和原生 Option 操作。音乐统一使用系统“当前播放”，不再提供媒体来源选择或专用客户端连接；系统接口不可用时不自动切到其他来源。针对当前播放器的必要控制仍按需请求权限。提醒事项页面默认启用，仍需用户点击连接才申请 EventKit 提醒事项权限；不申请日历事件、联系人或摄像头权限。关闭同步或失去权限时撤下待办活动，旧异步读取不能恢复失效数据。

## 计时器与数据保留

计时器只保存本应用当前计时的标识、阶段和截止时间；睡眠唤醒及重启后按实际截止时间恢复/结束，取消只删除这项记录。关闭计时器功能会取消当前计时。倒计时通知由应用运行期间的岛内提醒提供，不创建系统通知或后台守护进程。
