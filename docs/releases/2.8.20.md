# AirIsland 2.8.20（317）

## 更新内容

- 修复音乐暂停时进度条短暂前进后回退的问题，改善网易云音乐暂停与恢复时的进度连续性。
- 提高媒体时间数据精度，正确处理播放状态与播放速率分批更新，避免进度重复累加；保留用户主动向后拖动进度的行为。
- 调整设置侧栏选中样式，使用浅蓝色背景；窗口失焦时切换为系统弱化选中样式。
- 补充 README 演示视频、社区链接、提醒事项操作及歌词可用性说明。

## 安装与兼容

适用于 Apple Silicon Mac，要求 macOS 15 或更新版本。

沿用 2.8.19 的固定自签名证书及 Sparkle 更新签名密钥。安装包未经过 Apple 公证，首次打开可能需要手动允许；升级后相关系统权限可能需要重新授权。保留原有设置与用户数据。

已安装 2.8.19 的用户可通过应用内“检查更新…”升级；更早版本请先手动安装新版。

媒体修复属于活动来源层，侧栏样式属于呈现层；活动调度的优先级、期限与抢占规则保持不变。

真实网易云随机切歌、多显示器、侧栏激活与失焦效果、macOS 15 真机、系统权限继承及旧版原地升级仍需验收。
