# AirIsland 图标

`AirIsland-icon-master.png` 是用户选定概念的透明背景母版。造型为银白色圆角方形、石墨色刘海与展开卡片，以及蓝色发光接缝。

图像由 OpenAI 图像生成工具制作；透明背景整理提示要求保留选定造型，仅清除外部背景与零散像素，不添加文字、不改变比例或颜色。应用图标各尺寸由此母版通过 macOS `sips` 缩放导出。

应用图标位于 `AirIsland/Assets.xcassets/AppIcon.appiconset`，设置和欢迎页图标位于 `logo2.imageset`。

辅助进程 `AirIslandHelper` 使用同一套图标，ICNS 资源位于 `AirIslandHelper/AppIcon.icns`。
